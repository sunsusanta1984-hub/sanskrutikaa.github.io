1Deploy to Netlify (Free — 5 Minutes)

✓ Free Forever HTTPS Auto-Included Custom Domain Support

Netlify is the easiest way to host your PWA and is 100% free. HTTPS is required for PWA and Service Workers to work.

Option A — Drag & Drop (No account needed)

  • Go to app.netlify.com/drop in your browser
  • Drag the entire sanskrutikaa-pwa folder onto the page
  • Wait 30 seconds — your site is live!
  • Click "Change site name" → type sanskrutikaa
  • Your URL: https://sanskrutikaa.netlify.app ✓

Option B — Netlify CLI (For future updates)

# Install Netlify CLI once npm install -g netlify-cli # Login to Netlify netlify login # Deploy your PWA folder netlify deploy --prod --dir=sanskrutikaa-pwa # Your site is live at the URL shown ↑
💡 After deployment, update the manifest.json and AndroidManifest.xml with your actual Netlify URL (or custom domain like sanskrutikaa.com).

3Build Android APK with Bubblewrap (Google's Tool)

Trusted Web Activity Google Official Tool Free to Build

Bubblewrap is Google's official CLI to turn your PWA into a real Android APK using Trusted Web Activity (TWA). No Android Studio needed!

Prerequisites (One-time setup)

  • Install Node.js from nodejs.org (version 18+)
  • Install Java JDK 11+ from adoptium.net
  • Install Android SDK (or let Bubblewrap auto-install)

Build Steps

# Step 1: Install Bubblewrap npm install -g @bubblewrap/cli # Step 2: Initialize your TWA project mkdir sanskrutikaa-android && cd sanskrutikaa-android bubblewrap init --manifest https://sanskrutikaa.netlify.app/manifest.json # Bubblewrap will ask you these — here are your answers: Domain: sanskrutikaa.netlify.app App name: Sanskrutikaa Handlooms Short name: Sanskrutikaa Package name: com.sanskrutikaa.handlooms Start URL: /index.html Theme color: #0E4A50 Background: #0E4A50 Orientation: portrait Display: standalone # Step 3: Build APK bubblewrap build # Output: app-release-signed.apk ← This is your Android app!

Link Your Domain (Required for TWA)

Create a file at /.well-known/assetlinks.json on your website:

[{ "relation": ["delegate_permission/common.handle_all_urls"], "target": { "namespace": "android_app", "package_name": "com.sanskrutikaa.handlooms", "sha256_cert_fingerprints": [ "YOUR_SHA256_FINGERPRINT_HERE" ] } }]
⚠️ Get your SHA256 fingerprint after signing your APK with: keytool -list -v -keystore sanskrutikaa.keystore

Alternative: PWABuilder (Easiest — No Terminal)

  • Go to pwabuilder.com in your browser
  • Enter your URL: https://sanskrutikaa.netlify.app
  • Click Package for Stores → Android
  • Download your APK — done! ✓ (No coding needed)
